# Unison Player 0.5.2

## New: folders for songs and videos

- Make your own folders inside Unison ("Relax", "Pop", "Rock"…) from the
  **Folders** section in the sidebar (Android and iPhone: the Folders chip in
  the Library). The files stay where they are; a folder is only a list.
- Add songs and videos one at a time (right-click › Add to Folder), or choose
  several or all of them with **Select** › **Select All** › **Add to Folder**.
  "New Folder…" in the same menu makes a folder and fills it in one go.
- Inside a folder: Play, Shuffle, **Add Files…** and **Add a Folder…** pick
  music or videos straight from your computer. Select › Remove takes items out
  again. Right-click a folder to rename or delete it.

## Fixes

- **No more console window flashing up on Windows.** Looking up lyrics for a
  new song started `curl` with a visible console, so a black window appeared
  for a second every few songs. It now runs hidden.
- **Opening a video from Explorer ("Open with") shows the video properly.**
  If Unison was in the mini player, the video opened in a small corner window
  with only the sound, or drawn too large and cut off. Opening something from
  outside now always brings the full window, and the picture fits the window.
- **The window no longer opens squeezed together.** A window size saved by an
  older version could be smaller than the layout needs, so buttons and lists
  piled up on top of each other. Sizes are kept within the minimum now, and
  the mini player's size is never saved as the full window's.
- **The mini player's progress line can be dragged or clicked to seek**, for
  music and for video picture-in-picture.
- The yellow (minimize) and green (full size) window buttons swapped places;
  the red close button stays where it was.
- Keyboard media keys (play/pause, next, previous) were checked on Windows with
  the window in front, behind other windows and hidden in the tray. Windows
  sends them to the app that played media most recently.
