# Unison Player 0.4.0

First Unison release, imported from the verified 0.3.6 media player baseline.

- The application display name is **Unison Player**. Repository, Cargo package,
  executable, terminal command, resource filenames and technical identifiers use
  **unison**.
- The new U/play icon is used by the application, tray, Windows installer,
  Linux desktop integration and macOS app bundle.
- All established music, video, fullscreen, PiP, volume/mute, complete Close,
  offline Persian translation and subtitle continuity behavior is retained.
- Isolated Unison settings, cache, IPC and Windows installer identity allow the
  previous application to remain installed without sharing processes or data.
- Native GitHub Actions tests and publishes Windows x64, Linux amd64 and macOS
  Apple Silicon/Intel packages to `Nahur1/unison` after every required job passes.
- The shared repository supports collaboration with each contributor's real Git
  identity; real collaborators are no longer blocked by an owner-only hook.

macOS packages require macOS 15+ and have an ad-hoc signature, without Apple
notarization. Linux packages are DEB files tested on Ubuntu 22.04. macOS/Linux
updates are manual; installed Windows copies use the Unison update manifest.
