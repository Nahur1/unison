# Unison Player 0.5.1

- **Keyboard shortcuts work with the Persian keyboard layout.** With Persian
  input active, letter shortcuts (F fullscreen, T subtitle mode, M mute, N next,
  P previous, A A–B loop, E equalizer, Y lyrics, B notes, L favorite, V library,
  Ctrl+O / Ctrl+L / Ctrl+M) did nothing, because the same keys type Persian
  letters. Both Windows Persian layouts are understood now.
- **Shortcuts no longer stop working** after using the search box, or after
  closing the notes, link, new-session or equalizer-preset boxes with a button:
  the keyboard goes back to the player whenever a panel or view closes.
- Building the macOS disk image retries when GitHub's Mac runners briefly
  report "Resource busy", so a release is not held up by it.
- **Closing the window while music plays shows the mini player**, so
  it is clear Unison is still running. Closing the mini player keeps Unison in
  the tray; Quit in the tray menu exits completely.

## Android

- **Subtitles are found again.** Subtitles stored inside MKV and MP4 videos
  (SRT, ASS/SSA, WebVTT, MP4 text) are read when a video is added or first
  played. A subtitle file chosen together with its video (`Film.mkv` +
  `Film.srt` or `Film.en.srt`) is attached to it automatically, and the
  subtitle picker now lists `.srt` files, which Android used to grey out.
- **Persian translation starts by itself** as soon as a video has English
  subtitles, like on the desktop, with no need to press “Prepare” first.
- **CC no longer freezes the app.** Opening subtitle settings from a
  fullscreen video left an invisible fullscreen layer over the app that ate
  every touch; it now leaves fullscreen first.
- **Mini player works.** It uses Android's own picture-in-picture (Android 8
  and newer), and a playing video moves into it when you leave the app.
- **Fullscreen controls hide after three seconds** while a video plays, so
  they no longer cover the subtitles; a tap brings them back.
