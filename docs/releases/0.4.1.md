# Unison Player 0.4.1

- **Linux:** the DEB installs on Debian 13 and Ubuntu 24.04+ (libmpv2) as well
  as Ubuntu 22.04 (libmpv1); Unison loads whichever libmpv is installed.
- **Tray:** closing the window keeps music playing in the tray; **Quit** in the
  tray menu or `unison close` exits completely. Without a tray, closing quits.
- **Updates on macOS and Linux:** Unison shows when a new version is out and
  **Download** opens the release page. Installed Windows copies still update
  themselves.
- **About:** credits both authors, Reza Hashemian and Mohammad Fakhari, with
  links to follow them and star Unison on GitHub.
- README rewritten in English and Persian.
