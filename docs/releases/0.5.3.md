# Unison Player 0.5.3

Louder, steadier sound for videos (by Reza Hashemian), on top of 0.5.2.

- **The volume goes up to 150 %**, so quietly mixed films can be turned up.
  Above 100 % boosts; 100 % is the old maximum.
- **The volume slider follows loudness more evenly.** 50 % is now about
  -12 dB instead of -18 dB, so the lower half of the slider is usable.
- **One volume for the whole app.** Switching sessions no longer changes it.
- **Even out quiet videos** (Settings, on by default): soft dialogue in films
  and clips is brought up without loud scenes clipping. Music is not touched.
