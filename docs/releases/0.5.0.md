# Unison Player 0.5.0

- Add a mobile Android application for direct APK installation and an iPhone
  installable PWA, keeping the selected logo, fonts, palette and glass styling.
- Bring local music/video libraries, search, albums/artists, favorites, sessions,
  queue, playback controls, fullscreen/PiP, lyrics import, bookmarks/notes,
  sleep timer, A–B loop, equalization and themes to the shared touch interface.
- Reuse Unison's Rust English→Persian translator through a WebAssembly worker,
  with the same verified offline model, external subtitle modes and SRT export.
- Native Android music continues when locked and stops on complete task removal.
- Add signed Android APK and PWA ZIP build/checksum artifacts, mobile tests and
  GitHub Pages deployment, gated alongside the existing desktop release jobs.
- Document platform differences and preview limitations in docs/MOBILE.md.
- Include the new logo beside in-app desktop product headings from 0.4.1.

Mobile is a preview: actual Android/iPhone device acceptance is still required.
Safari and WebView codec/storage/PiP restrictions apply. Desktop embedded track
selection, cross-cue sentence merging, online link extraction and automatic EQ
are not represented as implemented mobile features.
