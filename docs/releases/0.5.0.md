# Unison Player 0.5.0

## New: Android and iPhone

- **Android app** (APK, direct install) and an **installable iPhone PWA**, with
  the same logo, fonts, palette and glass styling as the desktop app.
- Music/video library, search, albums/artists, favorites, sessions, queue,
  playback controls, fullscreen/PiP, lyrics import, bookmarks/notes, sleep
  timer, A–B loop, equalizer and themes on a touch interface.
- **Offline English→Persian subtitles** with the same Rust translator and the
  same verified model as desktop, external subtitle modes and SRT export.
- Android music keeps playing with the screen locked and stops when the app is
  closed with Stop and Close or removed from recent apps.
- Runs on **older Android phones (7–10)** whose system WebView was never
  updated (Chrome 69 or newer). Older WebViews show a short message asking to
  update Android System WebView.

## Desktop

- **Linux:** the DEB installs on Debian 13 and Ubuntu 24.04+ (libmpv2) as well
  as Ubuntu 22.04 (libmpv1); Unison loads whichever libmpv is installed.
- **Windows:** installing Unison closes and uninstalls **Kaghaz Player**, the
  app it replaces (its data folders are left alone).
- **Opening files:** a song or video opened from the file manager or the
  terminal joins the current session's list instead of replacing it.
- **Tray:** closing the window keeps music playing in the tray; **Quit** in the
  tray menu or `unison close` exits completely. Without a tray, closing quits.
- **Updates on macOS and Linux:** Unison shows when a new version is out and
  **Download** opens the release page. Installed Windows copies still update
  themselves.
- The U/play mark beside the Unison Player heading in the sidebar and About.
- **About:** credits both authors, Reza Hashemian and Mohammad Fakhari.
- README rewritten in English and Persian.

## Notes

Mobile is a preview. Safari and Android WebView codec, storage and PiP limits
apply; desktop-only features (embedded track selection, cross-cue sentence
merging, online links, automatic EQ) are not part of the mobile app yet. See
docs/MOBILE.md.
