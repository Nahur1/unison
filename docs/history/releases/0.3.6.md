# Kaghaz Player 0.3.6

- Native macOS disk images for Apple Silicon (arm64) and Intel (x86_64), including libmpv and its non-system dynamic dependencies.
- Native Debian/Ubuntu amd64 installer, with automatically calculated shared library requirements.
- Compatible startup with Ubuntu 22.04's libmpv, and macOS fullscreen on the current desktop without unstable overlapping Spaces transitions.
- Offline English-to-Persian model, Persian fonts, paper-P logo and license notices included in every package.
- Required native unit tests, real offline model inference, package installation/mount checks, and isolated playback/mute/mini/exit tests on Linux and both Mac architectures.
- GitHub Actions publishes all four platform builds together only after every required job succeeds. Windows automatic updates continue using the existing verified manifest.

Linux package targets Debian/Ubuntu systems compatible with Ubuntu 22.04 or newer; it is not an AppImage or RPM. macOS packages target macOS 15 or newer and are ad-hoc signed, not Apple notarized. First launch may require approval in System Settings > Privacy & Security. macOS/Linux updates are installed manually from Releases; the silent updater remains Windows-only.
